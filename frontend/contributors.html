🛠️ Who is doing what

🙌 Open roles - join us

You earn trust and access by showing up and doing solid work, decided by maintainers, not by a vote. Start small, pick any of these:

  • Code - fixes, features, performance, accessibility. Start with an issue on GitHub.
  • Translation & native review - improve or add a language (Bengali, Spanish, Hindi, Odia, Assamese, and more). Native-speaker review is especially valuable.
  • Marketing & outreach - help the right people find Banpani when a disaster hits.
  • Community verification - verify reports on the live map during an active response.
  • Design & docs - make it clearer and easier to use under stress.
